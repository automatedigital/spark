## Resulting behavior

The live explorer now uses `/list?paged=true&limit=200`, initially requesting only the root. Only expanded folders load children; explicit controls load further pages. Sorting is deterministic (directories, casefolded name, exact-name tie-break). Opaque cursors bind the canonical root, directory, hidden policy and directory revision; a changed directory rejects an old cursor with 409 and an explicit refresh instruction. The page selector retains only 201 candidates while scanning one directory, never recursing. Legacy autocomplete retains its existing unpaged contract.

The per-pane cache retains directory pages/revisions within project/visibility ownership. Mutations invalidate affected ancestors/subtrees; unrelated cached folders survive. Removed folders retire expansion and pending reads. Existing events with only a slug conservatively reconcile expanded folders because no affected path is available; events carrying a path narrow invalidation. Refresh supersedes an in-flight read for that directory. Project/visibility retirement aborts requests and fences success, error and finally updates.

Filename/path search walks the same bounded listing contract, one request at a time, at most 20 pages per continuation, and stops on the next matching page (at most 200 matches displayed). Continue searches beyond the initial pages without accumulating an unbounded result DOM. Query/project retirement aborts the active fetch and stops traversal. Abort does not interrupt an already executing synchronous OS directory scan on the server.

Hidden entries retain the explicit visibility switch. Existing listing imposes no Git-ignore exclusion; ignored files stay reachable rather than silently disappearing. Canonical linked project roots work. Internal/external/cyclic child links stay visible and labelled, but are not recursively expanded; external traversal is rejected. The legacy recursive helper also stops at links. Editor/preview/download/file-operation APIs remain existing contracts; no editor replacement.
