## Implementation

- Retain immutable message-source snapshots and turn start positions. Compare
  source identities to find the first affected turn, then reuse the preceding
  projections without grouping/building those turns. Tool and subagent metadata
  replacements rebuild the containing suffix. User/settled-answer edits, ID/order
  replacement, prepend, fork and compression use full grouping. Interleaved
  explicit turn IDs and suffix references into a prefix also fall back to full
  grouping, preserving the existing current-turn semantics.
- Optional per-call counters distinguish message comparisons, turn visits and
  rebuilds. `incremental: false` retains a full-grouping replay/reference path.
- Include grouping interruption in the existing reference-reuse guard. A newly
  appended redirect changes the previous turn even when its message objects are
  identical; the regression compares against a fresh full projection.
- Memoize `TimelineTurnGroup` and stabilize all its action adapters while invoking
  the latest committed callbacks/owner. Preserve callback presence and exact
  assistant source content. An opt-in row-commit counter uses the existing
  `spark_efficiency_test=1` bridge.
- Coalesce only live assistant text replacements into a single pending animation
  frame. Keep every latest snapshot; changes to decisions, tools, metadata,
  terminal state or session bypass/cancel that frame. Controller state and
  persisted content remain authoritative and unchanged. Virtualizer and scroll
  algorithms are unchanged.

No transport/read controller, context/compressor control, backend, dependency,
lockfile, manifest or packaged `web_dist` change is included.

## Limits and integration

The first-difference identity scan and output/source-array copies remain O(n).
This removes historical grouping/projection work, not all transcript-length work.
Input rows/metadata must be immutable; in-place mutations are not supported.
Interleaved explicit IDs deliberately trade speed for full-reference correctness.
Text presentation can wait for RAF in a background tab; terminal/decision/session
transitions bypass it. No real provider latency, installed macOS/Windows package,
external-service or release claim is made. CI/review were not polled by this child.

SP04 transport/read-controller and SP14 context-control owners remain independent;
only timeline projection and rendering hunks in ChatPanel changed. No merge,
release or packet completion checkbox is authorized by this report.
