## Result

- A metadata-only typed index supplies shell navigation, palette destinations,
  Settings order and search. The shell resolves Settings aliases as overlays,
  retaining the originating page/thread rather than selecting an invalid page.
- Common destinations lead: desktop connection, profiles, model, memory/context,
  skills/tools, saved MCP configuration, existing MCP tests and notifications.
  Common controls take one section/result selection after opening Settings.
- Exact labels and schema keys rank before breadcrumb matches. Search shows the
  breadcrumb, opens the owning child/category, reveals a closed Advanced fields
  disclosure and focuses the actual rendered control. Schema metadata loads on
  first search; inactive editors are not mounted to build the index.
- Existing legacy tab IDs resolve to the correct advanced child, including logs,
  analytics and admin. Current custom values and unknown config keys survive.
  Unknown schema categories remain indexed; raw YAML remains reachable.
- Existing draft ownership is retained across section unmounts. Outer wrappers
  associate existing labels with controls using unique IDs. Focus restoration
  waits for Enter keyup so selecting a model cannot reopen its dropdown.
  Settings contains keyboard focus and restores a visible opener on close.
