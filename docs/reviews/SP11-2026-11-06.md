## Implementation

`modelListLoader.ts` owns per-consumer AbortController/attempt generations and a
bounded memory-only model-ID cache. Identity includes requested provider and
endpoint, backend origin, transport connection generation, profile scope and
profile generation, provider-key epoch, and a private transport auth epoch.
Direct token storage changes also retire reads without putting token values in
cache keys. Saving a provider API key invalidates these entries and consumers.
Retired requests cannot publish results, errors, loading completion, or cache
entries even if the underlying request ignores cancellation. The domain model
client passes the native signal to the existing fetchJSON; shared transport and
api.ts/apiTypes are unchanged.

Cache bounds: 16 routes, 500 unique IDs per route, maximum ID length 1024,
30-second freshness. Expired entries are visibly stale and retained within the
same bound until intentional Refresh. Opening/remounting the selector only reads
memory. Refresh always bypasses cache. No discovery effect runs on mount, route
change, or popover open. The loader does not receive a config setter; only an
explicit user selection changes the draft. Selected custom IDs remain options
on empty/error responses and route changes. Loading, cached-stale, ready,
empty response and transport failure have distinct messages. Curated/non-live
results are identified as suggestions rather than confirmed provider access.

The rendered state belongs to its loader, avoiding a transient old-credential
list during replacement. Escape consumes the combobox key event so it closes
the model list while preserving Settings. A distinct accessible trigger label
makes the selected value distinguishable from an identical list option.

No backend changes or server dedupe were necessary. No competing generic cache,
provider resolver, persistence migration, configuration default, composer,
history, draft ownership, ChatPanel/controller, shared schema, manifest,
lockfile, web_dist, cron, tree or tracker implementation edits are included.
